# Синтетичні XLSX

Усі назви, File ID і resource keys вигадані. Жодна книга не містить приватних документів, токенів або Google credentials. Посилання `SYNTHETIC_*` призначені для підміненого HTTP в автоматичних тестах; успішного завантаження з реального Google Drive вони не забезпечують. Для ручної перевірки зробіть локальну копію та замініть URL власними дозволеними посиланнями. Копію з реальними даними не додавайте до Git.

Книги створено ClosedXML 0.105.1 без Office; автор у метаданих — `Synthetic samples`. Кеш формули записано безпосередньо в OOXML без її виконання. Тестовий проєкт копіює ці файли в `Samples` біля тестової збірки. Тести читають їх без збереження й перевіряють незмінність байтів.

| Файл | Вміст | Очікування на підміненому HTTP |
|---|---|---|
| [downloads.xlsx](downloads.xlsx) | П'ять рядків: PDF, Docs, Sheets, Slides і повтор PDF; Docs містить resource key | П'ять успіхів: `Звіт.pdf`, `Документ.docx`, `Таблиця.xlsx`, `Презентація.pptx`, `Звіт (2).pdf` |
| [validation.xlsx](validation.xlsx) | Змінені порядок/регістр заголовків, hyperlink, порожній рядок, чужий домен, відсутні значення, дві формули | Результати фізичних рядків 2, 4, 5, 6, 7, 8: валідні лише 2 і 7; рядок 3 виключено |
| [invalid-headers.xlsx](invalid-headers.xlsx) | Заголовки `Файл` і `URL` замість обов'язкових | Помилка книги до звернення до Drive |

У `validation.xlsx` рядок 2 використовує target гіперпосилання замість тексту «Відкрити документ»; назва `../../CON` перевіряє подальшу санітизацію імені. Рядок 7 має збережену назву `Кешована назва`, хоча формула дала б інший текст: ExcelReader використовує кеш. `HYPERLINK()` у рядку 8 не має кеша й стає помилкою. Якщо відкрити та зберегти книгу в Excel, кеші можуть змінитися; зберігайте вихідні приклади без змін.
